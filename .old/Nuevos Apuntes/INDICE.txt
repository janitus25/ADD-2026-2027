APUNTES JAVA - PERSISTENCIA EN FICHEROS (MP 0486)
=================================================

Cómo usarlo: abre la carpeta en VS Code. Cada .java se ejecuta con
    java NombreDelFichero.java
(los que crean ficheros los dejan en la carpeta desde donde ejecutas).

REGLAS QUE MÁS CONVIENE RECORDAR
--------------------------------
1. Texto: Reader / Writer
2. Binario: InputStream / OutputStream
3. Texto línea a línea: BufferedReader + readLine()
4. Texto escritura: BufferedWriter + write() + newLine()
5. FileWriter("fichero.txt") -> sobrescribe
6. FileWriter("fichero.txt", true) -> añade al final
7. read() termina con -1
8. readLine() termina con null
9. ObjectInputStream (y DataInputStream) terminan normalmente con EOFException
10. RandomAccessFile usa seek()
11. En acceso aleatorio el registro debe tener tamaño fijo
12. try-with-resources cierra automáticamente el fichero
13. Los streams deben cerrarse; try-with-resources es la forma recomendada
14. EOFException y FileNotFoundException van ANTES que IOException en los catch
15. Strings con equals(), nunca con ==
